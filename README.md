# wegopub

Hello World

wegopub is an app designed to raise competitiveness and fun for you and your friends.

## Project Idea (What is the idea and what makes it interesting?)

**Concept**: A mobile application where users visit bars, take pictures of their drinks, and capture locations on an interactive map.

**Main goal**: Encourage users to explore different bars and compete with friends by capturing and collecting locations.

**Core experience**: Users physically visit a bar, take a picture of their beer, and the app uses their GPS location to identify the bar. A successful check-in captures the location and updates their progress on the map.

## User Journey (What happens when someone opens the app for the first time?)

1. User is created (Name, etc., potentially a character like on Snapchat maps)
2. A lobby is joined (invite code)

## Core Functions (What does the interface look like?)

1. Personal profile segment
2. “Competition” segment of lobby you joined with leaderboard and statistics
3. + Function where you can take a picture etcetera
4. Memory Function of pictures you took
5. Live map where you can see territories

## Core Gameplay (How does capturing bars and territory work?)

1. Visit a bar; a user is physically at the location
2. Take a picture; a **photo is submitted** via the app
3. Verify the location; **match GPS coordinates** of the picture to a nearby bar
4. Capture the bar; **update the map** and **award points**

## Features

- **Photo**: pictures are uploaded → where stored?
- **GPS coordinates**: the app automatically detects where the picture was taken → how to detect?
- **Territory**: a territory is defined as area consisting out of an number of bars OR a geographical area
- **Award points**: different number of points are awarded for different drinks → create point scale
- **Bar capturing**: the player with the most points in a territory captures the territory
- **Live map**: a map is visible to all players seeing which territory belongs to which player
- **Memory function**: you can see all the pictures you took in the past, and are able to share those to other players if wanted
- **Games**: in app mini games to win points or similar
